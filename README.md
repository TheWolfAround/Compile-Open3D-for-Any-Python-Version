# Compile-Open3D-for-Any-Python-Version

The compilation script `compile_Open3D.bat` is self explanatory.

It clones the [Open3D](https://github.com/isl-org/Open3D.git) repository and my [Compile-Vulkan-Equipments-on-Windows](https://github.com/TheWolfAround/Compile-Vulkan-Equipments-on-Windows) script.

[Open3D](https://github.com/isl-org/Open3D.git) compilation script requires, first the [Compile-Vulkan-Equipments-on-Windows](https://github.com/TheWolfAround/Compile-Vulkan-Equipments-on-Windows) script to be run.

The wheel file for the Open3D will be copied into the working dir after a succeful compilation.
